5 · how we build

A code review before and after

The build is wrapped in two reviews, so we start from clean code and end with checked code.

step 1

Review before

A review of the code the build will change: Zorro Settings (zsettings), the Dialer (zorro-dial), Transfer and this session's commits. Bugs found get fixed first, or go into DEVS.

step 2

Build

In small steps, each tested in a private test screen and the VM, committed and pushed.

step 3

Review after

A review of everything the build changed, before you take it into use. Findings are fixed or listed.

The findings of both reviews will show on this page.

rules · in the repo as RULES.md

Build and design rules

Draft. The numbers are my proposal: change any of them in the note. A check in the repo (tools/check-rules) enforces the build rules before every commit.

Build: code stays split

  • One file, one job, at most 400 lines
  • One function at most 60 lines
  • One page = one file
  • Apps are packages: pages, logic and commands apart
  • Shared look and widgets live once
  • Older code may shrink, never grow (28 files are over a limit today)
  • Every page is opened in a test
  • A code review before and after a build

Design: direct, never long

  • App → menu → submenu → page, nothing deeper
  • A page fits one screen: no scrolling pages
  • One subject and at most 8 controls per page
  • At most 7 entries in a menu or submenu
  • Changes apply at once, no Save buttons
  • Labels at most 4 words, notes at most 2 lines
  • One look: the Zorro colours and font
  • Every page can be opened directly

instructions · things only you can do

Instructions

Steps that need you: an account, a password, a key. Each one says when it is needed.

needed for Mistral cloud

Create a Mistral API key

  1. Open console.mistral.ai and make an account (or log in).
  2. Choose a plan when it asks. There is a free one to experiment with; paid is per use.
  3. In the menu, open API Keys and press Create new key. Give it a name, e.g. zorro.
  4. Copy the key now: it is shown only once.
  5. On the laptop, save it in a file only you can read:
mkdir -p ~/.config/zorro-ai
nano ~/.config/zorro-ai/mistral.key
chmod 600 ~/.config/zorro-ai/mistral.key

In nano: paste the key, Ctrl+O, Enter, Ctrl+X. The key never goes into the repo. Never paste it into this page or a chat. The names of the menus on Mistral's site may differ a little.
